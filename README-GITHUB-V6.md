# DLOTUS-V6 — código para repositório privado

Este ZIP contém **arquivos-fonte** (não um deploy pronto). Extraia antes de enviar ao GitHub; não envie o ZIP como arquivo isolado.

**Não contém o banco MongoDB com cadastros reais.** O catálogo JSON de 245 itens é somente um arquivo de importação, não a prova de que os dados estejam no servidor.

A implantação online ainda requer: banco MongoDB hospedado, segredos no painel Render, HTTPS, build frontend e backend, autenticação revisada, CORS, backup/migração e sincronização offline/nuvem. **Não coloque em produção ainda.**

Nunca envie arquivos `.env`, senhas, chaves ou backup de clientes ao GitHub.
